# Din lokale diætist

A responsive Danish placeholder website for GitHub Pages, built with plain HTML and CSS. No build step, JavaScript, or package installation is required.

- `index.html`: Danish copy, services, sample prices, and placeholder contact information.
- `styles.css`: responsive layout and styling.
- `images/`: two original food photographs generated using the built-in image tool.

Open `index.html` in a browser to preview. GitHub Pages can publish this repository directly from the root of `main`.

Before launch, replace the example company details, services, prices, email, telephone, and address. Add real contact links, remove the placeholder notices, and remove the `noindex, nofollow` meta tag when the site is ready for search engines.

Lighting/mood: Soft sunny window light; joyful, welcoming everyday eating, no diet-culture styling. Constraints: No text, no people, no logos, no watermark.
